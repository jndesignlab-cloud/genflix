# GENFLIX
A static birthday website. Upload index.html and assets/ to the root of a GitHub repository. In Settings > Pages, select Deploy from a branch, main, /(root), Save. Open the published URL before sharing. No server, API, or dependencies required.
The greeting opens immediately; share the link at noon. No date lock is implemented. Photos are personal: ordinary GitHub Pages sites are publicly accessible even if not indexed; noindex is not privacy protection. Only publish with consent. The text is editable in index.html.

Version 1.1: mobile-first refinements, swipe photo viewer, visible YouTube soundtrack player. Playback may require tapping Play on mobile. Closing the player stops playback.
